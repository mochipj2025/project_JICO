# Prompt Maker オルゴナイト鑑定書

`index.html` をブラウザで開くと、フォーム回答から石の推奨セットと横長3:2の鑑定書原稿を作れます。同じフォルダのJSファイルも必要です。外部ライブラリやサーバー、AI APIは不要です。

## フォーム回答から作る（2026-10-01実装）

1. 初回だけ「制作設定」で使える石と標準素材、石の種類数上限を確認し、確認チェックを付けて保存します。初期一覧はサンプルで、実在庫の同期ではありません。
2. フォームの回答1件をまとめて貼り、「回答から自動提案」を押します。「サンプルで試す」も使えます。
3. 推奨セット・理由・代替セットを確認して採用します。複数の形の希望があるときだけ最終形を選びます。
4. 素材一覧、石のメッセージ、作品案、算命学の計算事実、本文下書きが自動で入ります。必要な文章だけ修正してコピーします。

回答は「設問：回答」、設問と回答を別行に置く文章、1件のJSON、見出し行と回答1件のTSV/CSVに対応。複数案件をまとめて貼る形式には対応しません。名前・生年月日・用途・願い・色・形・未来が必要です。メールアドレスは自動原稿に使いません。プレゼントでは受取人の情報を取り込みます。

出生時刻不明は12:00の暫定条件を明示します。算命学は正本から生成したengine-data.jsで一度取得し、raw付きSanmeiResultとして保持します。画面、原稿、案件JSONで原本を共有し、命式・星の手修正はできません。石選定は願いのカバーを優先し、未来の一致語、希望色を使います。未定義の算命学加点・誕生月加点はありません。

採用後の石差し替えは専用欄を使用します。関連原稿を再生成するため、その前に編集した文章を残す場合は案件JSONを保存してください。対応していない願い・色は表示し、勝手に補完しません。

「案件JSONを保存」で回答、計算原本、推奨セット、採用状態、編集内容を保存・復元できます。画像は含みません。回答や制作設定を変更したら採用状態を解除し、再提案・再採用が必要です。

## 標準の使い方

初期状態は「制作前：石選び・完成イメージを作る（写真不要）」です。制作前は写真登録欄を隠します。完成品の鑑定書を作るときだけ「完成後」を選ぶと写真登録欄が表示されます。旧版の初期設定で写真未登録だった保存内容も、一度だけ制作前へ切り替えます。

1. 「実物作品の鑑定書」または「作品イメージ」を選びます。
2. 実物作品写真と、必要ならレイアウト参考画像を選びます。
3. 確定済みの鑑定内容と採用素材を入力します。
4. 縮小プレビューと「拡大して確認」で配置を確認します。
5. 「生成前チェック」のエラーを解消します。文字数超過は警告として表示されます。
6. 「画像生成プロンプトをコピー」を押します。
7. 外部の画像生成ツールへプロンプトを貼り付け、画面に表示された画像を別途添付します。
8. 生成後の画像を確定原稿と一項目ずつ照合します。

## 保存と復元

- 文字入力、選択項目、案件名は入力停止から約0.5秒後に `localStorage` へ自動保存されます。
- 同じブラウザで再読み込みすると入力内容を復元します。
- 実物作品写真と参考画像の本体は保存しません。ページを再読み込みした後は再選択してください。前回のファイル名だけを案内として表示します。
- 「初期例に戻す」は確認後に実行されます。キャンセルすれば入力は変わりません。
- 初期化直後は「初期化前に戻す」で一度だけ文字入力を復元できます。画像は再選択が必要です。
- 通常編集は「元に戻す」「やり直す」で直近50回まで戻せます。この履歴は再読み込み後には残りません。

ブラウザの閲覧データを削除した場合や、別のブラウザ・端末では入力を復元できません。保存状態が「保存失敗」になった場合は、ページを閉じる前に生成プロンプトをコピーしてください。

## 画像の扱い

- 対応形式は JPEG、PNG、WebP、1枚10MB以下です。
- 選択した画像はブラウザ内でプレビューするだけで、自動送信しません。
- 実物作品写真は作品の形状・色・素材を伝えるために使います。
- レイアウト参考画像は配色・装飾・情報配置の参考専用です。参考画像の文章や作品を転用しない指示をプロンプトへ含めます。
- プロンプトをコピーしても画像本体はコピーされません。「画像生成時に別途添付する画像」の一覧を見て外部ツールへ添付してください。

## 入力と警告

- タイトル、作品テーマ、鑑定本文、素材1、あなたへのメッセージは必須です。
- 「実物作品の鑑定書」では実物作品写真も必須です。
- 必須不足やプレビューのはみ出しがある間はコピーできません。
- 推奨文字数を超えても文章は削除されません。警告を見て利用者が文章を調整します。
- 長文欄は内容に合わせて自動で伸び、ページ全体のスクロールで編集します。

## 現在の範囲と制限

算命学取得、石の推奨セット、定型文による原稿下書きは実装済みです。解釈文をAIで生成する機能、画像生成API、Googleフォーム直接連携、PDF出力、クラウド同期は未実装です。下書きはフォーム回答と既存カタログから作り、星から性格を推測しません。形・サイズに対する石数は制作設定の上限を使い、物理的な適合の自動判定はありません。プレビューの作品形・石の色見本は配置確認用で、実物の再現ではありません。

画像AIは日本語や長文を省略・変更することがあります。生成後は確定原稿、採用素材、実物写真と照合してください。
