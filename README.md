# Project JICO — オルゴナイト Prompt Maker

フォーム回答から算命学結果・石の推奨セット・作品構成・横長鑑定書用プロンプトを用意する、ブラウザで動く制作支援ツールです。

## 使い方

1. リポジトリをダウンロードし、`index.html` をブラウザで開きます。
2. 初回だけ、使用できる石・標準素材を制作設定へ保存します。
3. お客様1人分の質問と回答をまとめて貼り付けます。
4. 推奨セットを確認して採用すると、掲載原稿へ自動反映されます。
5. 必要な文章を修正し、画像生成用プロンプトをコピーします。

制作前は実物写真不要です。完成後の鑑定書を作る場合だけ写真を登録します。案件JSONの保存・読み込みに対応しています。

## 開発・検証

Node.jsで実行します。追加パッケージのインストールは不要です。

```sh
node "PromptMaker-縦横テンプレート/build-data.mjs"
node "PromptMaker-縦横テンプレート/test-workflow.mjs"
```

算命学の正本は `統合版ソース確認/sanmeigaku/engine.js`、既存石カタログは `凛の開運ナビ-鑑定書統合版/maker/stone-selector.js` です。ビルドは正本を変更せず、画面起動処理を除いたデータファイルを生成します。Golden Testは既存の確認済み5件を使用します。

## 現在の範囲

自動テストと模擬DOMで取り込み・採用・保存・差し替え・復元を確認しています。ブラウザでの実レイアウト確認は未実施です。Googleフォーム直接連携、AI API、PDF、実在庫同期、石の物理適合判定は未実装です。文章はフォーム回答と既存カタログから定型文で下書きし、命式をAIで推測しません。
