# むぎのオルゴナイト制作サポート

フォーム回答から石の選定と算命学計算を行い、両方を1枚にまとめる画像生成プロンプトを作成します。猫のむぎが操作を案内する、ブラウザで動く制作支援ツールです。

## 使い方

1. `index.html`をブラウザで開きます。
2. お客様1人分の質問と回答を貼り、「この回答から作成する」を押します。サンプルでも試せます。
3. 25種類のリストから使う石・素材を選び、メインを指定します。命式・計算条件も確認します。
4. 「画像プロンプトをコピー」を押し、画像生成が使えるChatGPTなどへ貼り付けます。
5. 生成画像の名前・石名・命式・文字を照合し、保存してお渡しします。

詳しいPDFが必要な場合は、任意の案内を開き、PDF用の依頼文と結果をコピーしてChatGPTへ渡します。完成画像は手動で添付してください。

## 表示と機能

- 三柱・日干・天中殺、十大主星の5方向、十二大従星3期とエネルギー、二十八元、節入り・計算条件を掲載。
- 依頼者の25種類から手動選択。おすすめボタンはリスト内の既存説明データがある素材だけを対象にし、採用後も変更できます。未登録素材の象徴や効能は創作しません。
- むぎの透過画像5枚、アイボリーと茶色のテーマ。本文18px・補足16pxを基本とし、スマホでも読みやすい文字サイズを維持。
- コピー完了後に成功表示。権限で失敗した場合は代替コピーを試し、手動コピーを案内。
- 完成画像のサンプルを掲載。サンプルは現在の回答の生成結果ではありません。

フォーム直接連携、AI API、サイト内PDF生成、端末間の在庫同期は未実装です。出生時刻不明は12:00の暫定計算。画像の文字や命式は生成後に照合してください。入力案件の保存は簡易画面では行いません。

旧鑑定書Makerは `PromptMaker-縦横テンプレート/index.html` に残しています。

## 素材の在庫管理

「素材の在庫管理」を開き、素材ごとに現在数・単位（g／個／袋）・補充目安を登録します。入荷では増えた量、使用では実際に使った量、棚卸しでは現在数を入力します。gは小数第3位まで、個・袋は整数です。

在庫はこのブラウザのlocalStorageに保存します。未登録と在庫ゼロは区別し、ゼロの素材はおすすめから除外します。在庫未登録の素材は未登録と表示したうえで選べます。選択済みの素材がゼロになった場合、入荷または選択変更まで画像・PDF用プロンプトを無効にします。素材を選ぶだけでは在庫は減りません。

入荷・使用・棚卸しの履歴を保存し、画面には最新20件を表示します。別ブラウザ・別端末とは同期しません。「在庫JSONを保存」でバックアップしてください。読み込んだJSONは、内容件数を確認して置換ボタンを押すまで反映されません。ブラウザのデータ消去で在庫も消えるため、移行前にJSONを保存してください。

基本性格×望む未来の固定画像プロンプト。日干・中心星と望む未来を使い、基本性格・大切にしたいこと3つ・未来へのキーワード・応援メッセージを全体500字以内で依頼。時間・回数・ノルマは指定しません。石を含む作品と1枚の画像にして外部AIで生成し、鑑定士が確認します。

メインは「本人の望む未来・好きな色を中心にした作品＋短いアドバイス」の画像生成プロンプトです。回答反映時に色を優先して石を仮選択し、鑑定士が変更できます。助言の根拠は日干・中心星と望む未来だけ。石の説明は作品側に使います。サイトのメインボタンはコピーまでで、画像生成AIへ貼り付け・送信して画像を作ります。詳細鑑定・詳細版画像・PDF・在庫は追加メニューです。

自由入力：生年月日と望む未来・相談内容があれば作成可能。例「1987年4月25日生まれ」改行「新しい仕事に自信を持って前進したい」。別名見出し（誕生日・目標・カラーなど）、既存フォーム、JSONにも対応。名前・用途・願い・色・形は省略可。日付が曖昧・複数、不正、未来が空欄なら作成しない。自由な文章の完全な意味解析は行わず、読み取り確認を表示する。複数人物は非対応。
選定素材のプロンプトに象徴・色・簡易特性を追加。既存データと水晶の制作テーマを使用。未登録の素材は未登録と明示し、商品名から組成・加工・効果を推定しない。石の情報は作品側に反映し、性格・行動の根拠には加えない。
石の簡易説明の確認先：[GIA アメジスト](https://4cs.gia.edu/en-us/blog/amethyst-variety-of-quartz/)、[GIA ローズクォーツ](https://www.gia.edu/rose-quartz-quality-factors)、[GIA アクアマリン](https://www.gia.edu/aquamarine)、[GIA ターコイズ](https://www.gia.edu/turquoise)。象徴のキーワードは既存の制作説明であり、鉱物学的な効果ではない。
